# Stargate Quantum Space

An original, browser-based quantum interface concept for visualizing a spatial field, monitoring signal conditions, and adjusting field variables.

## What’s included

- Animated field visualization with orbital paths and a central energy core
- Live-style field metrics
- Interactive phase offset and field intensity controls
- Signal-mode selector and configuration feedback
- Responsive, dependency-free HTML, CSS, and JavaScript

## Project structure

```text
.
├── dist/
│   ├── index.html     # Interface markup
│   ├── styles.css     # Responsive visual system and animation
│   └── script.js      # Field controls and interface behavior
└── .openai/
    └── hosting.json   # Private deployment configuration
```

## Run locally

The project has no build step. Open `dist/index.html` in a browser, or serve the directory with any static file server.

For example, with Node.js:

```bash
npx serve dist
```

## Deployment

The current version is deployed as a private site. Access requires the appropriate ChatGPT account permissions.
